# Visual Debugging

Use the screenshot or visual artifact as evidence, then connect it to the running app and code.

1. Identify visible defects: overlap, spacing, missing affordances, duplicate elements, clipped text, contrast, or inconsistent controls.
2. Reproduce the state in the browser when possible.
3. Inspect the relevant UI code before editing.
4. Make focused layout and interaction fixes.
5. Verify with a screenshot or DOM check at desktop and mobile sizes when the app is responsive.

Do not claim the image was unreadable if visual artifacts are available in the prompt context or harness artifact store.
