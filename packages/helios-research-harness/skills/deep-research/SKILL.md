# Deep Research

Use Helios Forge's harness runtime for research tasks.

1. Restate the research question as a short contract with scope, exclusions, and output format.
2. Gather sources through the configured source connectors or workspace corpus.
3. Extract claims and evidence separately. Do not let a citation stand in for verification.
4. Flag contradictions, novelty risks, missing primary sources, and stale evidence.
5. Return a concise report with a bibliography and an implementation handoff when code changes are implied.

Prefer primary sources, official docs, papers, source code, and reproducible logs. Mark speculative synthesis clearly.
